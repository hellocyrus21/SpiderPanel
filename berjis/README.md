# برجیس — آلارم اندیکاتور Matrix Series روی بله

سایت سبک PHP برای هاست دایرکت‌ادمین (سرور ایران):
چارت کوکوین + اندیکاتور **Matrix Series** در تایم‌فریم‌های **1m / 5m / 15m / 1h** برای **BTC، XRP، LINK و DOGE** در برابر USDT،
و آلارم **روی خطوط اندیکاتور** (نه قیمت) که به **بله** پیام می‌فرستد.

- بدون Node.js، بدون دیتابیس، بدون build؛ فقط آپلود فایل‌ها
- اتصال به کوکوین از طریق همان ورکر کلودفلر: `https://trade66.hellocyrus21.workers.dev/`
- بله سرور داخل ایران دارد و از هاست ایرانی بدون فیلتر در دسترس است (تلگرام از هاست ایران فیلتر است)

---

## نصب (حدود ۱۰ دقیقه)

### ۱. آپلود
1. محتویات پوشه **`public_html`** همین پروژه را زیپ کنید.
2. در دایرکت‌ادمین: **File Manager** ← `domains/دامنه‌شما/public_html` ← یک پوشه به نام `berjis` بسازید ← فایل زیپ را داخلش آپلود و **Extract** کنید.
3. مطمئن شوید پوشه `berjis/data` قابل نوشتن است (Permission = **755**؛ اگر خطای نوشتن گرفتید **775**).

### ۲. رمز عبور
فایل `berjis/config.php` را **Edit** کنید و این خط را عوض کنید:
```php
'admin_password' => 'change-me',
```
به مثلاً:
```php
'admin_password' => 'MyStrongPass-1404',
```
تا این رمز عوض نشود، ورود ممکن نیست.

### ۳. نسخه PHP
در دایرکت‌ادمین ← **Select PHP version** (یا PHP Selector) نسخه **7.4 یا بالاتر** (ترجیحاً 8.x) را انتخاب کنید. افزونه `curl` باید فعال باشد (معمولاً هست).

### ۴. کرون‌جاب (برای اینکه آلارم وقتی سایت بسته است هم کار کند)
دایرکت‌ادمین ← **Cron Jobs** ← یک کرون جدید:
- Minute / Hour / Day / Month / Weekday: همه `*`
- Command:
```
/usr/local/bin/php /home/USERNAME/domains/DOMAIN/public_html/berjis/cron.php >/dev/null 2>&1
```
به جای `USERNAME` نام کاربری دایرکت‌ادمین و به جای `DOMAIN` دامنه خودتان را بگذارید.

کرون هر ۱ دقیقه اجرا می‌شود و **داخل همان دقیقه هر ۱۰ ثانیه** آلارم‌ها را بررسی می‌کند؛ پس آلارم‌های ۱ دقیقه هم جا نمی‌مانند.

> اگر `/usr/local/bin/php` کار نکرد، از پشتیبانی هاست مسیر PHP-CLI را بپرسید.
> اگر اصلاً PHP-CLI نداشتید: در `config.php` یک مقدار تصادفی برای `cron_key` بگذارید و این دستور را در کرون بنویسید:
> ```
> wget -q -O /dev/null "https://DOMAIN/berjis/cron.php?key=همان_مقدار"
> ```

در صفحه آلارم‌ها پایین لیست نوشته می‌شود که کرون فعال است یا نه.

### ۵. بله
1. در بله با **@botfather** یک بات بسازید و توکن را بگیرید.
2. به بات خودتان یک پیام بدهید (مثلاً «سلام»).
3. در سایت ← **✉️ بله** ← توکن را وارد کنید ← «پیدا کردن چت‌آیدی» ← روی چت خودتان بزنید ← «ارسال پیام آزمایشی» ← «ذخیره».

> برای ارسال در گروه/کانال: بات را عضو (در کانال، ادمین) کنید، یک پیام در آن بفرستید و دوباره «پیدا کردن چت‌آیدی» را بزنید.

## استفاده

### چارت و اندیکاتور
- بالای صفحه: انتخاب ارز و تایم‌فریم (اندیکاتور همیشه روی همان تایم‌فریم چارت محاسبه می‌شود).
- **اندازه بخش اندیکاتور**: با اسلایدر/دکمه‌های `−` `+` روی پنل اندیکاتور، یا با کشیدن مرز بین چارت و اندیکاتور با ماوس. اندازه ذخیره می‌شود.
- **⚙️ اندیکاتور**: تنظیمات جدا برای هر تایم‌فریم (Smoother، SupResPeriod، SupResPercentage، PricePeriod، Overbought، Oversold) + رنگ و نمایش خطوط. دکمه «اعمال روی همه تایم‌فریم‌ها» هم هست.
- مقدار پیش‌فرض‌ها همان اسکریپت اصلی تریدینگ‌ویو است: `5 / 50 / 100 / 16 / 200 / -200`.

### خطوط اندیکاتور
| خط | توضیح |
|---|---|
| **Up** (آبی) | خط سریع Matrix |
| **Down** (نارنجی) | خط کند Matrix |
| کندل‌های Matrix | فاصله بین Up و Down؛ سبز یعنی Up بالای Down |
| **مقاومت / حمایت** | خطوط داینامیک بر پایه CCI |
| OB / OS | سطوح اشباع خرید/فروش (پیش‌فرض ۲۰۰ و ۲۰۰-) |

### ساخت آلارم (🔔 آلارم‌ها)
1. نماد و تایم‌فریم
2. **خط اندیکاتور**: Up / Down / مقاومت / حمایت
3. **شرط**:
   - **لمس**: وقتی خط به عدد هدف برسد (در محدوده ± که تعیین می‌کنید) یا از روی آن رد شود
   - **شکست به بالا**: خط از زیر هدف به بالای آن برود
   - **شکست به پایین**: خط از بالای هدف به زیر آن برود
4. **هدف**:
   - یک **عدد روی محور اندیکاتور** (مثلاً ۱۵۰). دکمه «📍 از روی چارت» را بزنید و روی پنل اندیکاتور کلیک کنید تا عدد خودکار پر شود. یا روی مقادیر فعلی (chip ها) بزنید.
   - یا **یک خط دیگر** (مثلاً «Up شکست به بالا ← مقاومت» یا «Down شکست به پایین ← OS»)
5. **زمان بررسی**:
   - **بسته شدن کندل** (پیشنهادی): فقط بعد از بسته شدن کندل، بدون سیگنال کاذب
   - **لحظه‌ای**: همان لحظه روی کندل در حال تشکیل (سریع‌تر، ولی ممکن است کندل برگردد)
6. **تکرار**: یک بار (بعدش خاموش می‌شود) یا هر بار (حداکثر یک پیام در هر کندل)

آلارم‌های عددی به‌صورت خط‌چین زرد روی پنل اندیکاتور دیده می‌شوند.

## اتصال به کوکوین (🔧 اتصال)
سایت به ترتیب این مسیرها را امتحان می‌کند و مسیری که جواب داد را به خاطر می‌سپارد:
1. ورکر، فرمت قبلی: `WORKER/?base=BTC&quote=USDT&interval=1m&limit=1000`
2. ورکر به‌عنوان پروکسی: `WORKER/api/v1/market/candles?type=1min&symbol=BTC-USDT`
3. کوکوین مستقیم (از ایران معمولاً بسته است)

فاصله زمانی کندل‌ها چک می‌شود؛ اگر ورکر برای ۱ دقیقه کندل ۱۵ دقیقه بدهد، رد می‌شود و مسیر بعدی امتحان می‌شود.
اگر در «تست اتصال» برای 1m یا 5m همه مسیرها خطا دادند، کد فایل **`cloudflare-worker.js`** را در همان ورکر کلودفلر جایگزین کنید (لینک عوض نمی‌شود).

اگر خطای SSL دیدید: در `config.php` مقدار `'ssl_verify' => false` بگذارید.

## ساختار فایل‌ها
```
public_html/          ← همین را آپلود کنید
  index.php           صفحه اصلی (چارت + پنل‌ها)
  api.php             API داخلی
  cron.php            بررسی آلارم‌ها (کرون)
  config.php          رمز و تنظیمات پایه
  lib/matrix.php      محاسبه اندیکاتور در سرور
  lib/market.php      دریافت کندل از ورکر + کش
  lib/alarms.php      موتور آلارم + بله
  assets/matrix.js    محاسبه اندیکاتور در مرورگر (دقیقاً مشابه matrix.php)
  assets/app.js       چارت و رابط کاربری
  data/               تنظیمات، آلارم‌ها و کش (خودکار ساخته می‌شود)
cloudflare-worker.js  کد اختیاری ورکر
dev/                  تست‌ها (آپلود نکنید)
```

## نکات فنی
- محاسبه اندیکاتور در مرورگر و سرور **یکسان** است (تست `node dev/parity.mjs` بیت‌به‌بیت مقایسه می‌کند)؛ یعنی عددی که روی چارت می‌بینید همان عددی است که آلارم با آن مقایسه می‌شود.
- ۱۰۰۰ کندل گرفته می‌شود تا EMA ها گرم شوند و اعداد با تریدینگ‌ویو هم‌خوان باشند (نسخه قبلی ۱۵۰ کندل می‌گرفت).
- در کندل‌های ریز ۱ و ۵ دقیقه، وقتی چند کندل پشت‌سرهم کاملاً صاف باشند، انحراف معیار صفر می‌شود. تریدینگ‌ویو آنجا خط را قطع می‌کند؛ اینجا مقدار قبلی ادامه می‌یابد تا اندیکاتور و آلارم قطع نشوند.
- دقت نمایش قیمت برای هر ارز جداست (DOGE پنج رقم اعشار، XRP چهار رقم …) تا کندل‌های ریز صاف دیده نشوند.
- فایل‌های داده با پسوند `.php` و هدر `exit` ذخیره می‌شوند؛ حتی اگر `.htaccess` کار نکند، از بیرون قابل خواندن نیستند.
- توکن بله هیچ‌وقت به مرورگر برگردانده نمی‌شود.
