عکس رهبران کشورها
--------------------
برای نمایش عکس هر رهبر، یک فایل JPG با نام کد سه‌حرفی کشور اینجا بگذارید:
  USA.jpg  RUS.jpg  IRN.jpg  TUR.jpg  CHN.jpg  IND.jpg  GBR.jpg  FRA.jpg  DEU.jpg  ...
اندازه‌ی پیشنهادی: مربعی، حدود ۲۰۰×۲۰۰ پیکسل.
اگر عکسی نباشد، حروف اول نام نمایش داده می‌شود.
نام و عنوان رهبران در data/leaders.js است.
